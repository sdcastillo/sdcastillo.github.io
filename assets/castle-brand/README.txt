Sam Castle brand drafts
=====================================

Effective Immediately.
Castillo means castle, and the castle is the rook, the piece that holds the line

	Brand
	-----
	Name: Sam Castle (from Castillo = castle)
	Mark: original geometric rook (chess piece) on a chess-grid board
	Primary colors: navy #0B1F3A / mid navy #163354 / gold #D4AF37
	Mono colors: black #111111 / charcoal #2A2A2A / white #F7F7F7
	Type: Liberation Sans Bold (SIL Open Font License; already on this machine)

	Tools used
	----------
	- Hand-written SVG (original rook path; no clip art)
	- Python 3.14 + Pillow 12.3 to rasterize PNG (Inkscape and rsvg-convert
	  were not installed; nothing was installed)
	- ImageMagick 7.1.2 was available as a fallback but was not required

	  98x98 watermark / corner badge

	  Left: chess grid + rook badge + TITLE TEXT
	  Right: empty dashed frame labeled REAL PHOTO OF SAM HERE (no face)
	channel_banner_draft.svg/.png (2560x1440)
	  Wordmark "Sam Castle" + "Predictive AI" and the rook sit inside the

The rook path is an original silhouette (five merlons, collar, neck,
shaft, stepped base). It was not copied from clip art or a font glyph.
