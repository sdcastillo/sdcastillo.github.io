## The scene

Sam at college meets his friends at the library after closing time. They have booked a room on Saturday while the rest of UMass is at the football tailgate. Sam’s friend Ben brings in a box of Dunkin and a box of coffee.

“Time to grade all those Freshmen Calc I homework labs,” says Ben.

“Sounds like your TA gig has been keeping you busy,” chortles Sam.

“Honestly, reviewing the ways these brilliant minds are solving trig problems is inspiring. It’s all anonymous so I don’t see names, though I see the handwriting and the intelligence behind the problem-solving. This last assignment used complex numbers and Euler’s identity instead of just the shortcut sin²x + cos²x = 1…”

“Whiz kids…” whistled Sam.

We gotta keep sharp on math if we want to be the first to Mars.

## UGRID

This blog started in college before 2018. I was still a newbie programmer. It was Sam’s network version 1.00. The blog came out of UGRID — Undergraduates Interested in Data — an extracurricular. I’d voluntarily give up my Saturday mornings, when I could have been out with friends or studying for assignments, to code. Write code, eat donuts, build cool projects with other smart developers, hackers, entrepreneurs. I was part of other entrepreneurship groups at UMass Amherst. My friends would chat about space, about Elon Musk, SpaceX, the future of humanity, aliens. We never got graded. There was no “I need this to pass the exam.” It was the idea: if we win this hack competition and build an app or software that has world-changing potential, perhaps Elon or a tech supercompany will find us and scale it up. I had to learn Ruby on Rails from scratch. I used Jupyter Notebooks knit to HTML, then added those to Ruby on Rails webpages. That was before ChatGPT or Claude Code. If there was one bug in the Jupyter Python code it spilled over into the rendered HTML, then when converted to Ruby I’d render the site, wait two hours for the DNS build git worker to finish, then find the error and have to rebuild.

## Behind the scenes

How this movie was made without a GPU.

- Story written through character-roleplay prompts with a Dolphin chatbot.
- Visual planning in Google Notebook LM plus hand sketches.
- Clips generated with Grok Imagine from real reference photos.
- RAG used to keep Sam’s appearance and context grounded instead of drifting.
- Assembled with ffmpeg and Python on ordinary hardware — no dedicated GPU required for the final cut.
