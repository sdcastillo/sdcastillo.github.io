## Process

1. **Source clips** — Generate or capture short video segments (AI animation from real photos, real footage, guitar, city, space, etc.).
2. **Organize** — Name files by theme and time. Keep durations and order in a list.
3. **Normalize** — Scale everything to 1920×1080, 30 fps, consistent audio.
4. **Sequence** — Arrange clips into a narrative flow (intro → hook → scenes → closer).
5. **Blend** — Crossfade transitions (usually 1.5 s) so cuts feel continuous.
6. **Render** — Final encode with audio, faststart for web.
7. **Publish** — Upload to Rumble, embed on this site.
